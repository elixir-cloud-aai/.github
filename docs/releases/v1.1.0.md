# v1.1.0

Release v1.1.0 of the shared actions of ELIXIR On-Cloud adds the action
`publish-release`, which creates the GitHub release of a tag from a
repository's release workflow, with the curated notes followed by GitHub's
generated notes (the organisation's release notes format), and checks in the
`prepare` job that the release can be created. The actions `gate`, `pr-title`
and `scan-image` are unchanged. Callers pin
`elixir-cloud-aai/.github/actions/<name>@<commit> # v1.1.0`; Dependabot
proposes the update.
