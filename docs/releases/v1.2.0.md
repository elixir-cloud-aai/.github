# v1.2.0

Release v1.2.0 of the shared actions of ELIXIR On-Cloud adds the input
`assets` to the action `publish-release`, which attaches files (e.g., a
packaged Helm chart) to the GitHub release, also in repositories with
immutable releases. The action `scan-image` gets the input `fail-on-pip`
(default `false`): set it to `true` to fail scans of images that contain
pip. The README of the action `gate` now documents the workflow
`concurrency` settings that let only a new commit cancel the runs of a pull
request, so that a cancelled run doesn't leave a failed gate; the action
itself is unchanged, and callers adopt the settings in their own workflows.
The action `pr-title` is unchanged. Callers pin
`elixir-cloud-aai/.github/actions/<name>@<commit> # v1.2.0`; Dependabot
proposes the update.

## Features

- Attach release assets in publish-release (#77, #79).
- Add the opt-in `fail-on-pip` to scan-image (#55, #74).

## Fixes
