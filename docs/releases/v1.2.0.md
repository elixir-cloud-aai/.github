# v1.2.0

Release v1.2.0 of the shared actions of ELIXIR On-Cloud adds the input
`assets` to the action `publish-release`, which attaches files (e.g., a
packaged Helm chart) to the GitHub release, also in repositories with
immutable releases. The action `scan-image` now fails scans of images that
contain pip, and the action `gate` cancels pull request runs only for new
commits. The action `pr-title` is unchanged. Callers pin
`elixir-cloud-aai/.github/actions/<name>@<commit> # v1.2.0`; Dependabot
proposes the update.

## Features

- Attach release assets in publish-release (#77, #79).
- Fail scans of images with pip (#55, #74).

## Fixes

- Cancel PR runs of the gate only for new commits (#72, #71).
